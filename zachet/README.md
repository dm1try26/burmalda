# Зачёт — апгрейдер (учебный проект)

Сайт в стиле CS-апгрейдеров на игровой валюте, только вместо оружия — вещи для учёбы. Кредиты ненастоящие: их нельзя купить за деньги или вывести.

## Предметы

Шесть категорий: канцелярия, тетради, книги, напитки, калькуляторы, ноутбуки. Предметы идут от самых бесполезных к самым ценным:

| Полезность | Примеры |
|---|---|
| Бесполезное | Сонник, ручка без пасты, калькулятор без «=» |
| Пригодится | Гелевая ручка, кофе из автомата, учебник 1987 года |
| Полезное | Ежедневник, инженерный калькулятор, свежий справочник |
| Очень нужное | Методичка преподавателя, тетрадь отличника, ноутбук студента |
| Незаменимое | Годовой запас кофе, зачётка с автоматом, мощный ноутбук, красный диплом |

## Как запустить

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

Удобнее через VS Code с расширением **Live Server**: правой кнопкой по `index.html` → *Open with Live Server*.

## Структура

```
index.html      разметка всех страниц (templates/zachet/)
_icons.html     SVG-иконки предметов, общие для апгрейдера и личного кабинета
css/style.css   оформление (цвета и шрифты задаются в :root вверху файла)
js/data.js      предметы, степени полезности, износ, ящики, настройки шансов
js/skins.js     узоры предметов и функция, которая рисует иконку
js/app.js       логика: апгрейд, ящики, магазин, статистика, звук
js/inventory.js инвентарь в личном кабинете (/profile): продажа и «В апгрейд»
```

## Что где менять

| Задача | Где |
|---|---|
| Добавить или изменить предмет | `js/data.js`, массив `RAW` |
| Добавить ящик | `js/data.js`, массив `CASES` |
| Комиссия, максимальный шанс, стартовый баланс, бонус | `js/data.js`, строка с `EDGE`, `MAXCH`, `START`, `BONUS` |
| Цвета сайта | `css/style.css`, блок `:root` |

## Как считается шанс апгрейда

```
шанс = стоимость ставки / цена цели × 0,95   (не больше 80%)
```

Выпадает случайное число от 0 до 100. Если оно меньше шанса в процентах, апгрейд удался.

Прогресс хранится в `localStorage` браузера под ключом `zachet1`.
