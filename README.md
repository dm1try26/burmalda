# Double — игра для учебного казино

Мини-игра «Double» на Flask. Игрок ставит виртуальные фишки на **красное**, **чёрное** или **зелёное**, лента прокручивается, и выпадает число от 0 до 14.
Настоящих денег нет — проект учебный.

## Правила

| Ячейки | Цвет    | Выплата | Шанс  |
|--------|---------|---------|-------|
| 0      | зелёный | x14     | 1/15  |
| 1–7    | красный | x2      | 7/15  |
| 8–14   | чёрный  | x2      | 7/15  |

Возврат игроку (RTP) для любой ставки: 14/15 ≈ 93,3 %.
Стартовый баланс — 1000, ставка от 1 до 10 000. Если баланс закончился, появляется кнопка «Начать заново».

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Открыть: http://127.0.0.1:5000/ (перенаправит на `/double/`).

Секретный ключ сессии берётся из переменной окружения `SECRET_KEY` (для разработки есть значение по умолчанию).

## Тесты

```bash
python -m pytest
```

Покрыто: игровая логика (выигрыши, проигрыши, валидация ставок, распределение шансов) и все маршруты API.

## Структура проекта

```
app.py                  # фабрика приложения, регистрация blueprint'ов
double/
  __init__.py           # экспортирует double_bp
  logic.py              # чистая логика игры (без Flask)
  wallet.py             # баланс и история (сейчас в сессии)
  routes.py             # Blueprint: страница и JSON API
  templates/double.html
  static/double.css
  static/double.js      # анимация ленты, ставки
tests/
  test_logic.py
  test_routes.py
```

## API

| Метод | Путь                  | Описание |
|-------|-----------------------|----------|
| GET   | `/double/`            | Страница игры |
| POST  | `/double/api/spin`    | Тело: `{"color": "red\|black\|green", "amount": 100}`. Ответ: результат, новый баланс, история. При ошибке — 400 и `{"error": "..."}` |
| GET   | `/double/api/state`   | Баланс и последние числа |
| POST  | `/double/api/reset`   | Сброс баланса и истории |

## Как подключить к общему проекту казино

1. Скопировать папку `double/` в общий проект.
2. Зарегистрировать blueprint:

   ```python
   from double import double_bp
   app.register_blueprint(double_bp, url_prefix="/double")
   ```
3. У приложения должен быть задан `SECRET_KEY` (баланс пока хранится в сессии).

### Общий баланс между играми

Весь доступ к балансу идёт через четыре функции в `double/wallet.py`:
`get_balance`, `set_balance`, `get_history`, `add_history`.
Чтобы перейти на базу данных или единый кошелёк для всех игр казино, достаточно заменить их реализацию — логика и маршруты менять не придётся.
